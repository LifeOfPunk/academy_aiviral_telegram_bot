## Проблема 1: Крипта - 404 ошибка ✅ ИСПРАВЛЕНО

**Что было:**
- При оплате криптой ошибка: `Request failed with status code 404`
- URL: `https://app.0xprocessing.com/Api/CreateInvoice`

**Причина:**
- Неправильный API endpoint для 0xProcessing

**Решение:**
- Изменен baseUrl с `https://app.0xprocessing.com` на `https://api.0xprocessing.com`
- Файл: `src/services/PaymentCrypto.service.js`

**Статус:** ✅ Исправлено, бот перезапущен
